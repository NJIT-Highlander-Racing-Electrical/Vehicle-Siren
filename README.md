# Vehicle Siren
This project is mostly "for fun". Plays sound files using an ESP-32 and a DFPlayer Mini connected to the speaker in a mini bullhorn.
## About
An ESP-32 controls the DFPlayer Mini via serial, which then plays .mp3 files from a MicroSD card. Skipping tracks, pause/play, etc. can be done via buttons.
## Planned Features
- Playback control:
  - Skip track
  - Go back to last track
  - Pause/unpause playback
  - Volume control
 - Make it spin?
## Components
- ESP-32
- DFPlayer Mini
  - MicroSD Card
- Speaker (currently using a bullhorn)
